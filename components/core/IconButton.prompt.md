One-line: icon-only button for slider arrows, search toggles and the circular social row in the footer.

```jsx
<IconButton label="Next visual" variant="outline"><Icon name="chevron-right" /></IconButton>
<IconButton label="Instagram" shape="circle" variant="solid"><Icon name="instagram" /></IconButton>
```

Use `shape="circle"` only for social/media discs — everything else stays square.
