One-line: the Medartis action control — square, Roboto Medium, black fill for primary and a 1px black outline for secondary.

```jsx
<Button variant="primary" size="md">Read more</Button>
<Button variant="secondary" iconRight={<Icon name="arrow-right" />}>Download IFU</Button>
<Button variant="inverse" href="/contact">Contact us</Button>
```

Variants: `primary` (black/white), `secondary` (outline, fills black on hover), `inverse` (white on black surfaces), `ghost`, `link` (text with the sky-300 underline that the brand uses for links). Sizes 32/40/48px. Never round the corners.
